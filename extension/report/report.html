2. What FormGuard reads, and never reads

Reads (on your device only)

  • The field's label, type, name/id, placeholder and format attributes (pattern, min/max, required)
  • The website's own error message text (shown only on screen)
  • How many characters were typed: a number, never the characters
  • For a chosen file: its size and type. Its picture width and height only when the site asks for pixel sizes (decoded in memory, then forgotten)

Never reads, stores or sends

  • What you type into any field (passwords, Aadhaar, PAN, OTP and so on)
  • File contents or file names (the name is shown on your screen only)
  • Your browsing history: it never lists your tabs or pages
  • Anything to a server, unless you switch on "AI help" (off by default; then only field names and error text, sanitised twice)

6. Check it yourself

  1. Open any page with a form. Press F12, open the Network tab and tick "Preserve log".
  2. Trigger some form errors and use the tooltips. Look at the "Initiator" column or filter by chrome-extension://.
  3. You will see zero requests from FormGuard while "AI help" is off. The "Requests sent" row above stays at 0.
  4. In chrome://extensions, open FormGuard, then Details: you can see and revoke every permission.
